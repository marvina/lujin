# 鲁锦·生成艺术工作台 (Lujin Generative Art Studio)

> **齐鲁民间织锦（国家级非物质文化遗产）数字化数理织律建模与生成艺术 Web 系统**  
> 适用：非遗数字化保护、新国风纺织品与服装设计、中式文创生成、数字孪生与计算美学教学。

---

## 一、 项目背景与艺术解构

**鲁锦**（又称鲁西南民间织锦）流传于山东鲁西南地区（鄄城、嘉祥等），2008年被列入国家级非物质文化遗产名录。鲁锦虽为纯棉手工织造，但因“图案繁复、绚丽似锦”而被誉为“锦”。

在深入研读 `/01调研/案例/ref/鲁锦` 目录中的田野实物与历史样本后，本项目将其核心艺术与织造特征提炼为三大计算维度：

1. **经线起花与二进制织律（Warp-faced Compound Weave）**  
   传统鲁锦通过“多综多蹑”木织机（提花机）织造，核心工艺是**“经线起花”**。经纱在不同综片牵引下浮沉（上浮形成“经组织点”，下沉形成“纬组织点”）。每一个传统经典纹样，本质上就是一个二进制矩阵（`0` 与 `1`），天然具备生成艺术（Generative Art）与离散计算美学的基因。
2. **多尺度层级骨架（Macro-to-Micro Dual Hierarchy）**  
   - **宏观格局**：大合斗、九眼透、水波长流水、八棱花瓣、百折彩带。
   - **微观肌理**：席纹（Basketweave）、阶梯犬牙（Houndstooth）、鱼眼全浮点（Floating Pearl）、经纬交错阴影与棉纱毛羽感。
3. **高对比度的齐鲁民间色彩调式**  
   传统植物与矿物染色谱系，善用强烈互补撞色（青花蓝白、朱砂红配栀子黄、孔雀蓝配大红等），在经纬交叠的微观尺度上产生极具冲击力与温润感的光学混色（Optical Color Mixing）。

## 三、 系统功能架构与技术栈

- **零依赖纯纯原生 Web 架构**：纯原生 JavaScript (ES6+)、HTML5 Canvas 2D 物理光影管线、现代响应式 CSS，无需 Node.js 编译黑盒，双击或直接启动静态服务器即可使用。
- **高保真织物渲染引擎 (`renderer.js`)**：
  - **物理圆柱光影**：精准模拟棉纱经纬交错时的凹凸圆弧面、阴影压纹与光泽。
  - **经线起花全浮长高光**：针对“花经全浮”点应用立体浮雕高光增强。
  - **织造须边（Fringes）**：逼真呈现手工织物边缘的流苏肌理。
  - **无级交互视口**：支持鼠标平移、滚轮缩放（0.4x 至 6.0x），支持移动端触控。
- **综蹑组织图模式 (`Draft Blueprint`)**：
  - 呈现传统织布机黑白/红白穿综矩阵与 8 格循环线，直观呈现织造技术配方。
- **非遗实物文创展厅 (`mockup.js`)**：
  - 实时将生成的纹样映射到 **中式蓬松方枕**、**挂轴布卷**、**茶席桌旗** 与 **四方连续壁纸** 上，自带布料自然褶皱与垂坠光影。
- **程序化织机声音合成 (`audio.js`)**：
  - 基于 Web Audio API 纯代码实时物理建模合成老木织机“飞梭穿梭沙沙声”与“筘框打纬木质敲击声”，带给用户沉浸式非遗织造体验。
- **多维度专业导出**：
  - 📸 **超清大图 (PNG)**：超清抗锯齿大图导出。
  - 📐 **矢量代码 (SVG)**：无限无损放大、无缝平铺矢量代码，方便导入 Illustrator / 工业打样。
  - 📦 **数字织机配方 (JSON)**：包含经纬排色表、综片数、纱支密度等结构化数据。

## 四、 快速启动与体验指南

### 方式 1：直接双击运行
直接在文件管理器中双击打开 `index.html`，即可在任何现代浏览器（Chrome、Safari、Edge、Firefox）中完整流畅体验所有功能。

### 方式 2：本地 Python 静态服务（推荐）
在终端中进入本项目目录并运行：
```bash
python3 -m http.server 8080
```
然后在浏览器中访问：`http://localhost:8080`
